# คู่มือติดตั้งเวอร์ชัน PHP / HTML / CSS / JavaScript

โฟลเดอร์ `php-app/` เป็นระบบบริหารจัดการการแข่งขัน **มาฆบูชาคณะสงฆ์อำเภอศีขรภูมิ** ที่พัฒนาด้วย **PHP / HTML5 / CSS3 / Vanilla JavaScript** แบบสมบูรณ์ ไม่ต้องใช้ Node.js, Vite หรือการ Build เพิ่มเติม

## โครงสร้างไฟล์
- `index.php` — หน้าหลักและโครงสร้าง HTML
- `config.php` — การตั้งค่าข้อมูลรายการแข่งขัน ระบบจัดเก็บข้อมูล (`data/db.json`) และ Session
- `api.php` — REST API ฝั่ง PHP สำหรับเข้าสู่ระบบ สมัครแข่งขัน บันทึกคะแนน แจ้งไม่เข้าร่วมแข่งขัน อัปโหลดรูปภาพ และตั้งค่าระบบ
- `assets/css/style.css` — สไตล์ชีตทั้งหมดของระบบ
- `assets/js/print.js` — ระบบจัดรูปแบบบัตรประจำตัว เกียรติบัตร ใบลงทะเบียน ใบบันทึกคะแนน และสั่งพิมพ์/บันทึกเป็น PDF
- `assets/js/app.js` — โลจิกหน้าเว็บและการเชื่อมต่อกับ `api.php`
- `.htaccess` — ป้องกันการเข้าถึงโฟลเดอร์ `data/` และไฟล์ `config.php` โดยตรง

## วิธีนำไปใช้งานบน Web Hosting (cPanel / DirectAdmin / Plesk / XAMPP)
1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด **ภายใน `php-app/`** ไปยังโฟลเดอร์ `public_html/` (หรือโฟลเดอร์ย่อยที่ต้องการ เช่น `public_html/makha/`)
2. ตรวจสอบให้โฟลเดอร์ `data/` และ `uploads/` มีสิทธิ์เขียนไฟล์ได้ (เช่น `755` หรือ `775`) — ระบบจะสร้างให้อัตโนมัติเมื่อเปิดหน้าเว็บครั้งแรก
3. เปิดเว็บไซต์ผ่านเบราว์เซอร์ได้ทันที (รองรับ PHP 7.4 และ PHP 8.x)
